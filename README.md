# Java POO - Exercícios Práticos

Coleção de exercícios em Java para praticar conceitos fundamentais de Programação Orientada a Objetos (POO).

## Conteúdo do repositório

- `Ex01.java` a `Ex16.java`: exercícios independentes, cada um com um método `main`.
- `Java_Basico_Parte_4_Programacao_Orientada_a_Objetos_Do_Zero_Ao_Avancado.pdf`: material de apoio.

## Pré-requisitos

- [JDK](https://adoptium.net/) instalado (Java 8 ou superior).
- Terminal com `javac` e `java` disponíveis no `PATH`.

## Como compilar e executar

No diretório do projeto, compile e execute o exercício desejado. Exemplo com o `Ex01`:

```bash
javac Ex01.java
java Ex01
```

No Windows PowerShell, os mesmos comandos funcionam:

```powershell
javac Ex01.java
java Ex01
```

> Observação: alguns exercícios solicitam dados via entrada padrão (`Scanner`). Execute-os em um terminal interativo para fornecer os valores quando solicitado.
